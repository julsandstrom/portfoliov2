# Portfolio v2

A portfolio built with Next.js, TypeScript and Tailwind CSS with a strong focus on accessibility, performance and user experience.

## Why I built it

My goal was to create a portfolio that reflects how I approach frontend development: clean architecture, accessibility-first thinking and fast user experiences.

## Key Features

- Responsive design
- Keyboard navigation support
- Semantic HTML
- Accessibility-focused implementation
- Optimized performance with Next.js
- Project showcase with detailed case studies

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## What I Learned

This project helped me improve my understanding of:

- Component architecture
- Accessibility and WCAG principles
- Responsive design
- Performance optimization
- UX-focused frontend development
